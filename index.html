我只管主 session 不要爆掉，雲端 agent 那一輪花了 90 美元

Anthropic 送的 250 美元只能在雲端用，我拿來做一個完全放手的和風卡牌遊戲，順便學怎麼管雲端 agent 的用量。我只限制主 session 不要爆，它就把工作全派給子代理，一輪花掉 90 美元。改成一個 Sonnet 做到底只花 31，但做的量只有四分之一。

BRIEFING 第一次來，先讀這三篇

  1. 技術開發 來電在 Mac 接、鏡像用 Touch ID 解鎖：我花了五週寫一個會說小米 Lyra 的 KDE Connect

    五週從協議層寫出會說小米 Lyra 的 KDE Connect：來電在 Mac 接、鏡像用 Touch ID 解鎖，工具自己長出來的旗艦作。

  2. 文化觀察 我需要一份「我不是壞人」說明書：當身障者的技術需求被 AI 攔截

    為了關掉一個干擾我的手勢去問 AI，被攔截。這篇是這個站最常回到的主題：身障者的技術需求，怎麼在分類器眼裡變成嫌疑。

  3. シルシ　我和她的事 Believe in myself - 獻給在某時某刻聽到這首歌的某個人

    2015 年第一次進 LiSA 演唱會現場的完整故事，站上十週年紀念區塊連結的就是這一篇。
