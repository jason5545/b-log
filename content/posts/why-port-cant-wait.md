# 不是 agentic coding 的時代，我只能等官方手機版，然後呢？

10/21 早上，我跟 Claude Code 聊到為什麼要自己移植那兩款卡牌遊戲，回了它一句英文，翻成中文是：「如果不是 agentic coding 的時代，我根本做不到，只能等官方。然後呢？」

前兩篇講的是別的事。10/16 的〈[卡牌 roguelike 明明最適合手機，官方手機版卻總要等一兩年以上](https://b-log.to/cultural-insights/card-roguelike-mobile-port-wait/)〉查官方手機版為什麼拖這麼久，10/20 的〈[我沒有用 REA：原版 DLL 直接跑，Unity 遊戲移植只剩引擎要自己重做](https://b-log.to/tech-development/without-rea-unity-original-dll-port/)〉寫原版程式怎麼跑在自己做的引擎上。我自己為什麼不等，兩篇都沒寫。跟前兩篇一樣，這兩款遊戲都是我自己買的，移植給自己玩，不散布。

## 等官方要等多久

第一款遊戲上市一年多，官方手機版到現在連公告都沒有。我自己估，至少要等五年。這是我的估計，不是查得到的時程。查得到的是它的前一代：PC 版 2020 年 5 月上市，Android 版 2025 年 5 月才出，晚了整整五年，而我用的剛好就是 Android。

第二款遊戲我原本也以為等不到。10/5 我開工時，官方還沒有任何消息，10/9 發行商才宣布手機版 2027 年 1 月上市，比 PC 版晚兩年三個月。上架那天我會去買，當作支持。

## 然後呢

等，前提是等得到。

10/19，Key 所屬的ビジュアルアーツ（Visual Arts）發了一份[公告](https://nhp.visual-arts.jp/wp/wp-content/uploads/2026/10/VA20261019_JP.pdf)，講的是《Angel Beats!》的原作麻枝准。他從今年春天開始覺得喉嚨不對勁，入夏後腫痛變得明顯，精密檢查之後診斷出咽頭癌。公告說，他反覆考慮過自己的病情和治療的前景，為了保留體力專心創作，決定不做積極治療，以緩和照護為主，現在在住院。他原本打算在 YouTube 長期經營一個新的音樂企劃，因為覺得能創作的時間所剩不多，改成盡快把構想中的歌做完，陸續公開。公告最後寫，他住院中也還是「最後まで創作に専念したい」，想專心創作到最後。

這不是他第一次住院。2016 年他因為特發性擴張型心肌症住了四個多月，裝上人工心臟，出院時說「助かったのは奇跡です」，能撿回一命是奇蹟（[日刊スポーツ，2016/7/3](https://www.nikkansports.com/entertainment/news/1672725.html)、[7/28](https://www.nikkansports.com/entertainment/news/1685921.html)）。

LiSA 剛開始發片時唱的，就是麻枝准的歌。2010 年《Angel Beats!》播出，劇中樂團 Girls Dead Monster 第二代主唱ユイ的歌聲由 LiSA 負責（[Sony Music 的 LiSA 簡介](https://www.sonymusic.co.jp/artist/lisa/profile/)）。那一年用 Girls Dead Monster 名義發的〈Thousand Enemies〉、〈Little Braver〉和專輯《Keep The Beats!》，詞曲都是麻枝准（[ORICON](https://www.oricon.co.jp/prof/509063/lyrics/166427/)、[anison.info](http://anison.info/data/source/33862.html)）。她以個人名義出道，是 2011 年 4 月的迷你專輯《Letters to U》。隔年第一張完整專輯《LOVER"S"MiLE》，最後的特別曲目〈終わりのない歌〉，也是麻枝准作詞作曲（[Sony Music](https://www.sonymusic.co.jp/artist/lisa/discography/buy/SVWC-7826)）。

麻枝准也寫了我會放進棺材的那款遊戲。我在〈[智代アフター，那個沒有奇蹟的故事，留得最久](https://b-log.to/cultural-insights/tomoyo-after-no-miracle-stays-longest/)〉寫過，那個故事沒有奇蹟，朋也接受腦部手術，短暫恢復記憶，然後走了。麻枝准說，他想描繪的是 Staff Roll 裡那隻熊，不管下雪、下雨還是刮風，都繼續走。看到這份公告，我心裡想的是，他現在可能也成了自己筆下的朋也。所以「最後まで創作に専念したい」這句話，我覺得講的是他，也是我：還做得到的時候，就去做。

我說的「然後呢」，就是這個。等官方，前提是時間一直都在，可是沒有人保證。

我自己的身體，我感覺得到它在退化。我操作電腦靠語音和一根手指，高中程式設計還不及格，10/16 那篇寫過，這兩款遊戲的程式都是 AI 寫的。這幾件事放在一起，就是我要自己做這兩款移植的原因。

## AI 讓我做得到，但不是有 AI 就做得到

「如果不是 agentic coding 的時代」這句話要講清楚。今年 1 到 3 月那三次失敗，也是用 AI 做的。10/20 那篇把差別主要放在方法上：動刀的位置換了、修正留得住、網頁版先鋪好了兩週。

我也問過，差別是不是 prompt 技巧。回頭查原始對話，答案是不是。1/4 我交給 Claude Code 的審查任務，開頭就寫「1:1 完全還原，不是重新設計」，prefab 和場景檔也要讀，結果做出來還是四不像。10/5 開工那天，我只丟了一句話。開工之後，同一個模型一樣先往「參考原作重做」的方向走，React 做介面、改成直式手機，直到 52 分鐘後我回它要完整、忠實地重現，才整套換掉。

後來我跟 Claude Code 說，不要把我的看法全盤當真，找另一個 AI 自己去翻原始對話和 git 紀錄，重新判斷一次。它特別註明，下面是判斷，不是測量。它認為缺一條就會回到 1 到 3 月的，有三件事。第一是路線，原版的資料和程式照用，修正放在重跑得回來的地方。第二是回饋迴圈和平台，1 月是在沒有 GPU 的虛擬機上做，還要等 iOS build，10 月是 Mac 實機和可以 root 的 Android，幾秒就開機，還有一條不開畫面也能操作的控制管道。第三是我的否決和標準：10/5 開工後很快拉回範圍，10/10 定下移植要跟原版一樣，10/19 決定整個搬過去。模型更強和前兩週的網頁版是加速項，讓它只花 28 小時做出整個引擎，但不是做成的原因。它的粗估是路線加回饋約一半，我約三成，模型加累積的東西約兩成。

它也指出我自己沒想到的一點：1 月的路線也是我選的，當時我接受的標準是能 build、能跑。方向一直是我在決定，10 月多出來的是標準，還有拉回的時機。從 1 月到 10 月，AI 都在附和我當下的方向，這點沒變。變的是這次我手上有東西可以玩、可以量，不滿意的時候，有地方可以對著講。

## 我享受這件事

那天 Claude Code 還問我，逐像素對照、做到 120 FPS 這些投入，是在替「能玩」服務，還是已經變成在做工程。它擔心工程會吃掉同一批時間。我回它：「對，我享受這個過程。」做的過程本身，就是我想要的那部分。

第二款遊戲的官方手機版 2027 年 1 月上架，我會去買。第一款遊戲的官方手機版什麼時候出，我不知道，我也不打算等。

因為麻枝准的消息，這幾天我又回頭聽起やなぎなぎ。他們 2012 年合作的《終わりの惑星のLove Song》裡有一首〈Last Smile〉，裡面有一句：

> 触れあうことなくても確かに触れあってたよ
>
> 即使不能接觸彼此　也確實觸及彼此了
