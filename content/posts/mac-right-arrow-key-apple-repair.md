# Mac 右方向鍵失靈，這次 Apple 幫我處理好了

之前我寫過一篇[〈Genius Bar 最會修的，是流程裡已經存在的問題〉](https://b-log.to/business-insights/apple-support-genius-bar-process-black-box/)，抱怨 Apple 的客服。訂單狀態、訂閱明明有卻用不到、Mac 通話接不起來，遇到這些問題，客服常常只能帶著你檢查設定、重新開機，再往下就不知道了。

9 月 12 日，我因為 Mac 鍵盤的問題去了 Apple 直營店。這次的經驗很直接：工程師清出了異物，現場重新測試，當天處理完。

這次怎麼發現問題，倒是有點特別。

我在用 Claude 桌面版的 Code 分頁。每輪回答結束後，輸入框會出現灰色的下一句提示文字，按右方向鍵就能填進去。

我按了，填不進去。

其他鍵正常，所以開始懷疑實體右方向鍵有問題。但光是在 Claude 裡按不出來，還不能確定原因，我請 Claude 陪我到終端機測試。

## 先看看按鍵有沒有送出訊號

測試用的是 `read -sk`，讓終端機等待鍵盤輸入，再實際按下右方向鍵。

測了兩次，收到的都是空的。

指令是這樣，執行後十秒內先按左方向鍵、再按右方向鍵：

```bash
read -sk 3 -t 10 a; read -sk 3 -t 10 b; printf 'left: %q\nright: %q\n' "$a" "$b"
```

正常的鍵會印出 `\C-[[D` 或 `\C-[[C` 這種指令碼，壞掉的鍵印出空字串。拿一個正常鍵當對照，就能分辨是鍵盤硬體壞了，還是某個 app 的快捷鍵設定有問題。

過程中，Claude Code 也試過用程式模擬右方向鍵。不過，模擬按鍵繞過了實體鍵盤，就算能動，也回答不了手指按下去為什麼沒反應。要查這顆鍵，還是得實際按。

帶著這個測試結果，我把 Mac 送到 Apple 直營店，也一起反映 R 鍵、T 鍵接觸異常的狀況。

接手的工程師叫 Hank。他從右方向鍵裡清出很多異物，R 鍵跟 T 鍵的狀況則還可以。另外又用壓縮空氣罐清潔了整個鍵盤，也清出不少東西。

我平常一直有用鍵盤膜，還買了三片輪流換。主要是想避免鍵帽用到泛油光，影響之後轉售的價值。睡覺前要合上螢幕，也一定會先把膜拿掉。我自己也曾經用壓縮空氣罐吹過鍵盤。

即使這樣，這次還是從按鍵裡清出了異物。至於異物到底怎麼進去，工程師沒有下定論。但鍵盤膜不是密封的，邊緣和掀開的時候都會進東西，膜本身又會把這些東西悶在鍵縫上。膜不是不能用，只是膜底下也要定期擦，不能因為蓋著就當作乾淨。

## 這次終於知道怎麼進診斷模式

這次也學到一件事：配備 Apple 晶片的 Mac，要怎麼進入 Apple 診斷。

先關機，再按住電源鍵，持續按著，直到出現啟動選項才放開。接著按住 **Command＋D**，直到 Mac 重新啟動，就會進入診斷程序。這個操作也可以對照 [Apple 的官方說明](https://support.apple.com/zh-tw/102550)。

以前不知道這個入口，這次終於知道了。

店方跑完 Mac 診斷，所有項目都是綠燈、通過。我沒有再跑一次終端機指令，直接實際按右方向鍵試，這次有反應了。再打開螢幕上的鍵盤檢視器，按下去對應的鍵會亮，也正常。案件當天結案。

送修前，終端機測不到這顆鍵的訊號。清潔後，按下去有反應。方法不一樣，但要回答的問題是同一個：手指按下去，Mac 有沒有收到。

## 之前的抱怨，跟這次的經驗

回頭看之前那篇文章，我抱怨的是：當問題超出客服熟悉的流程，他們常常沒辦法繼續往下查。

這次遇到的情況就很具體。右方向鍵沒有反應，Hank 檢查、清潔，清出異物後，我們重新測試，按鍵恢復正常。

這件事沒有推翻我之前的抱怨，反而印證了它。鍵盤有異物，是 Apple 流程裡本來就有的問題：檢查、清潔、跑診斷、複測、結案，每一步都有位置。我上次卡住的那些事，訂單分歧、訂閱狀態、FaceTime 的勾選，都不在任何流程裡。

之前那些客服經驗，我還是會抱怨。這次 Hank 幫我把鍵盤處理好，也應該一起記下來。
