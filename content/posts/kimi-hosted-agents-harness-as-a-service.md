# Kimi 把 Harness 做成雲端服務，我要的是自己機器上那排狀態牌

11 月 5 日，月之暗面正式發布 [Kimi Hosted Agents](https://www.kimi.com/news/kimi-hosted-agents)。官網上的說法很直白：把支撐 agent 運行的 Harness，做成雲端服務，企業不用自己架、也不用自己養那一套執行環境。文件裡還畫了一張對照表，一邊是模型推理 API，適合自己做 harness、要精細控制；另一邊就是這次的託管智能體，適合長時間或非同步的任務，不必自建沙箱和會話基礎設施（〈[產品概覽](https://platform.kimi.com/docs/hosted-agents/overview)〉）。

我讀到的時候，先注意到的是這個字。Harness，最近我剛好在自己的工作流裡用得很兇。

## 我這邊的 harness，本來就不在雲端那一層

10 月底我寫過，Theo 把 T3 Code 講成 ADE，不是 harness；真正叫模型、管上下文、讀檔改檔的，還是 Claude Code、Codex、Kimi Code 那些（〈[我說 T3 Code 變成很奇怪的變體，Theo 剛好拍了一支影片說它不是 harness，是 ADE](https://b-log.to/tech-development/theo-harness-ade/)〉）。我每天在 T3 裡派工，Kimi 就是其中一家。模型用它的，有時整家 harness 也用它的，但執行的地方在我自己的機器上：家裡的伺服器、Mac、綁在 tailnet 裡的那套介面。

更早一點，10 月中我換成自己架的 T3，原因也很具體。躺在床上只剩一支手機的時候，我要先看得見哪個對話串在跑、哪個在等我、哪個卡在用量、哪個掛了，狀態要掛在對話串本身，不能只活在一則推送訊息裡（〈[Anthropic 說 agent 有八成時間在等人，我在床上用 Telegram 叫了一天，隔天就換成自己架的 T3 Code](https://b-log.to/ai-analysis/anthropic-agents-waiting-t3code-server/)〉）。那篇寫完到現在，這條線沒變：可以改、可以 commit，push 還是等我。

所以 Hosted Agents 講的「不用自建 harness」，對很多企業是真實的成本。對我來說，自建那一層本來就不是為了炫技，是為了狀態看得見、機器在自己手上、跨機器調度還走自己的網路。

## 它賣的是底座，我買的是模型位

官方文件把產品拆得很清楚：沙箱、會話、重試、排程、技能與插件、審計匯出，再加按量計費（模型 token、沙箱時長、插件呼叫）。也就是說，它賣的是「讓 agent 跑得起來」的那一層底座，而且預設跑在它的基礎設施上。企業若要自訂安全檢查，還有 Inference Hook；英文整理稿寫到，部分自託管選項仍要企業認證，工具結果還是會回到平臺的模型推論介面，因此不能當成完整的私有部署。

我沒有去開 Hosted Agents 的控制台，也沒有拿自己的專案試跑。所以這篇不談好不好用，只談它跟我現在的切法差在哪。

我現在跟 Kimi 的關係，比較像文件對照表左邊那一欄：我要模型，有時也要它的 coding agent，但 harness 和 ADE 那圈控制面留在自己這邊。T3 選單裡換到 Kimi，規則和 skill 還是讀我自己那個資料夾；對話串狀態還是掛在我自己的伺服器上。雲端託管的 harness 若把會話史、沙箱狀態、產出檔都留在服務端，那正好是我 10 月中決定從 Telegram bot 搬走的方向的反面：狀態又回到別人的訊息流或別人的控制台裡，我躺著掃一眼的那排牌子就還原不成現在這樣。

## 企業省得到的，我這邊省不掉

Hosted Agents 的目標客戶寫得很明白：內部監控、運維回應，或是產品裡嵌投研助手、客服助手。那種場景，自建一套會話與沙箱確實可能花好幾個月，之後還要一直養。月之暗面把這層做成服務，邏輯上說得通。

我的場景不一樣。我要調度的是好幾家模型與工具，要它們碰我本機與 tailnet 上的東西，要手機上先看到誰在等我，還有一些刻意只留在本機的資料不能跟著會話進別人的雲。這些不是多裝 140 個官方 skill 就能替換的。skill 我可以接；底座我已經有了，而且是為了自己的操作成本長出來的。

所以看到「Harness as a Service」，我的結論很窄：這對需要託管環境的人是一條路；對我這種已經把 Kimi 接進自己 ADE 的人，新聞的意義比較像確認一件事。大家都在為 harness 付錢或花時間，只是有人付在雲端訂閱，我付在自己機器上的維護，以及每天掃那排狀態牌的力氣。我暫時沒有要把那排牌子搬進 Kimi 的控制台。
